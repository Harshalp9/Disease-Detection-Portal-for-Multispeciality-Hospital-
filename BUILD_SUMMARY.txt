QUICK START
================================================================================

1. START FRONTEND (Terminal 1)
   $ pnpm dev
   → http://localhost:3000

2. START BACKEND (Terminal 2)
   $ cd backend
   $ pip install -r requirements.txt
   $ python -m uvicorn app.main:app --reload
   → http://localhost:8000

3. ADD YOUR MODELS
   See MODEL_GUIDE.md for instructions
   Place in: backend/models/

4. OPEN DASHBOARD
   → http://localhost:3000/dashboard
   → Navigate to imaging modules
   → Upload medical images
   → View AI analysis

See STARTUP.md for detailed instructions.

MODEL SUPPORT
================================================================================

DENTAL ANOMALY DETECTION
  Format:    PyTorch (.pth)
  Classes:   normal, caries, periapical_lesion, impaction, bone_loss, root_anomaly
  Input:     Dental X-rays (JPG/PNG/WebP)
  Output:    Class name + severity + recommendations

CHEST X-RAY ANALYSIS
  Format:    TensorFlow SavedModel
  Classes:   normal, pneumonia, TB, COVID-19, pulmonary_edema, nodule, pleural_effusion
  Input:     Chest X-rays (JPG/PNG/WebP)
  Output:    Per-disease confidence scores + clinical notes

FRACTURE DETECTION
  Format:    PyTorch (.pth) - Ready for integration
  Classes:   normal, hairline, stable, displaced, comminuted
  Input:     Bone X-rays (JPG/PNG/WebP)
  Output:    Fracture type + severity + affected bone

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

Can't connect to API?
  □ Ensure backend running: curl http://localhost:8000/
  □ Check .env.local has correct URL
  □ Verify port 8000 available

Models not loading?
  □ Check files in backend/models/
  □ Verify file names match expected names
  □ See MODEL_GUIDE.md for format requirements

Image upload fails?
  □ File must be <10MB
  □ Format must be JPG, PNG, or WebP
  □ Check browser console (F12) for errors

Port in use?
  □ Find process: lsof -i :8000
  □ Kill: kill -9 <PID>
  □ Or use different port

See STARTUP.md for detailed troubleshooting.
